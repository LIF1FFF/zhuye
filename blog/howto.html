如何发布一篇博客文章

2026-09-05

本站的博客文章是纯 HTML 文件，放在仓库根目录的 blog/ 文件夹中，发布起来很简单，步骤如下：

第一步：创建文章文件

  1. 打开 GitHub 仓库，进入 blog/ 文件夹；
  2. 点击右上角 Add file → Create new file；
  3. 文件路径填写为 blog/文章名.html（建议用英文字母命名，如 blog/my-post.html）；
  4. 也可以复制已有文章（如 blog/hello.html）作为模板修改内容。

第二步：写文章内容

每篇文章都包含：标题（h1 标签内）、日期（class="meta" 处）、正文段落（p 标签）。想插入小标题可以用 h2 标签。

第三步：把文章加入列表

  1. 打开首页文件 index.html；
  2. 在 JS 中找到 blogPosts 数组，按同样格式添加一行：
    { title: '文章标题', file: 'blog/文章名.html' }
  3. 保存并提交（Commit changes）即可。

刷新网站后，点击首页「博客」按钮就能看到新文章了。
